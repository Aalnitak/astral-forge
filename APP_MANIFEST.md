# Forja Astral
### Astral Forge

> *Cada acción forja una estrella. Cada estrella construye un legado.*

---

# El Manifiesto de Forja Astral

Forja Astral es una aplicación para acumular puntos, pero tambien algo más.

Es una herramienta para construir constancia.

Creemos que las grandes personas no se forman por grandes acciones, sino por pequeñas decisiones repetidas durante años.

Cada tarea completada representa una decisión correcta.

Cada decisión correcta deja una marca permanente.

Así como las estrellas forman constelaciones, nuestros hábitos forman quienes somos.

---

# Nuestra Filosofía

No premiamos únicamente el resultado.

Premiamos el esfuerzo.

No importa si la tarea fue pequeña.

Importa que fue realizada.

La verdadera recompensa no es el premio que se obtiene.

La verdadera recompensa es convertirse lentamente en alguien mejor.

---

# El Universo

La aplicación ocurre dentro de un universo simbólico inspirado en el cielo nocturno.

No existe un final.

No existe un "100% completado".

Así como el universo continúa expandiéndose, también lo hace el crecimiento personal.

Cada usuario construye su propio firmamento.

---

# La Forja Astral

La Forja Astral representa el lugar donde las acciones cotidianas se transforman en estrellas.

Cada tarea completada aporta energía al firmamento personal del usuario.

Nada de lo construido desaparece.

Las recompensas pueden gastarse.

El crecimiento permanece.

## 1. Toda acción cuenta.

No existen tareas demasiado pequeñas.

Hacer la cama.

## 2. La constancia vale más que la intensidad.

No buscamos días perfectos.

Buscamos semanas consistentes.

Meses consistentes.

Años consistentes.

## 3. El progreso nunca termina.

No existe un nivel máximo.

No existe una última misión.

Siempre existe una nueva estrella por descubrir.

---

## 4. Cada usuario tiene su propio camino.

No todos realizan las mismas tareas.

No todos tienen la misma edad.

No todos persiguen los mismos objetivos.

La aplicación acompaña el crecimiento de cada persona.
